# Project Brief: 考研 Agent 规划系统

## 1. Project Identity
- **项目名称**: 考研 Agent 规划系统
- **目标考试**: 深圳大学信息工程学院 通信工程专业型硕士研究生初试
- **初试日期**: 2026-12-19（倒计时基线：2026-08-19 起 122 天）
- **核心价值定位**: 用 Obsidian 保存学习事实与决策，用 Agent 降低记录和复盘摩擦。系统必须服务于真实复习成效，不以功能数量作为成果，不挤占主线复习时间。

## 2. Target Scores & Subjects
- **目标总分**: **350 分**
  - **数学一**: 120 分（教材/题集：张宇基础、高数二刷、880、拼好卷、真题）
  - **英语一**: 70 分（真题精读推进：2010年起，留指定三年冲刺）
  - **政治**: 60 分（基础做题、套卷练习与主观题提炼）
  - **专业课 805**: 100 分（通信原理【樊昌信第七版】 + 信号与系统【奥本海姆】）

## 3. Core Principles & Design Invariants
1. **单一数据源 (Single Source of Truth)**:
   - 可执行任务状态：唯一保存在 `考研任务看板.md`（Kanban）。
   - 每日执行事实：保存在 `00_Daily/YYYY-MM-DD.md`（Daily 只记已发生事实，不预填计划）。
   - 本周承诺：当周 `周计划/*-正式.md`。
   - 调整与纠偏：当周 `周复盘/YYYY-Www.md`。
   - 系统行为规范：以 `SPEC.md` 为统一最高契约。
2. **AI 与用户的权限边界**:
   - AI（Pi、Claude Code、Codex）负责提炼信息、生成草案与建议。
   - 用户是唯一最终决策者（周计划生效、目标变更、规则晋升均需人工确认）。
3. **证据分级机制**:
   - 严格区分 `official`（官方大纲）、`user_fact`（用户真实数据）、`external_claim`（博主外部经验）、`ai_synthesis`（AI建议）、`personal_decision`（用户批准决策）与 `personal_evidence`（经个人验证的规律）。
   - 外部材料不可直接标记为已验证。

## 4. Scope & Non-Goals
### In Scope
- 双闭环学习流：周计划草案与正式发布、Kanban 任务生命周期、Daily 事实审计与周复盘。
- 方法论资产化：通过 Nuwa 技能将外部名师（如 MMG）经验文字稿分层蒸馏为候选规则，并建立契约测试。
- 错题闭环（M2 规划）：数学一真题与模拟题的高效错题摄取、复习与回写。
- 定时审计自动化（Antigravity 服务器）：只读健康检查与早晨学习材料投递。

### Out of Scope / Non-Goals
- 严禁在当前阶段建立复杂的专用 RAG 业务数据库或向量检索平台，优先利用 Markdown、Dataview 与 Agent 文件检索。
- 严禁根据外部经验自动改写正在进行的正式排程。
- 严禁自动 Git Push 或破坏性脚本覆盖。
