# MMG 数学方法论 Phase 2 综合摘要

> [!success] 用户检查结果
> 2026-08-23：用户确认五个模型不合并，其余 Phase 2 结构正确，允许进入 Phase 3。五个模型仍保持独立；本文件仍是 `ai_synthesis`，不代表规则生效。

## 1. 综合范围与结论等级

本次只综合“考研数学复习方法论”，不综合英语、政治、805，也不声称还原博主完整人格。18 条材料覆盖基础、强化、错题、习题册、拼好卷、A4、真题和证明题取舍，足以建立一个**数学领域顾问模块**。

证据层级如下：

- 原始视频文字稿：外部材料，证明“博主说过或表达过”。
- Phase 1.x 研究：AI 对材料的结构化整理。
- 本摘要：AI 对重复主张、触发条件、矛盾和边界的综合。
- 个人 W35 Daily：只用于验证“是否适合用户”，不能反向证明博主观点为普遍真理。

因此以下模型都标记为 `ai_synthesis`，不进入 `rules/active/`。

## 2. 心智模型候选

### 模型一：先把“正餐”做成可检验输出，再使用补充材料

**一句话：** 主线讲义和习题是学习主体，视频、技巧课和额外资料只能在暴露具体薄弱点后作为补丁。

**来源证据：**

- `mmg-src-14`：基础阶段不要把 UP 主专题课当主食，先做主线讲义和配套习题。
- `mmg-src-04`：强化习题遇到困难时，先看文字解析，再看针对性视频，最后才考虑专题课。
- `mmg-src-12`：日常做题通过即时反馈把输入转成下一题的输出。

**可运行形式：**

```text
如果尚未通过自主做题暴露具体缺口，先不新增视频或资料。
如果已经有明确章节、题型和失败点，再使用最小范围的补充材料。
补充材料结束后必须回到题目或闭卷复述，不能以观看时长结算。
```

**局限：** 该模型主要针对数学复习资源管理，不足以判断 805 或其他学科的视频价值；当主线材料本身无法解释问题时，机械拒绝补充材料也会变成反模式。

### 模型二：用“阶段门槛 + 人群分层”替代统一路线

**一句话：** 同一项任务是否应该做，不由资料名称决定，而由学习阶段、基础水平、正确率、目标和剩余时间共同决定。

**来源证据：**

- `mmg-src-05`：高基础、正确率达标者可能跳过线代强化；普通学生不能照搬。
- `mmg-src-10`：概率论安排必须与高数、线代和整体进度协调。
- `mmg-src-02`、`mmg-src-18`：真题或拼好卷的启动时机取决于强化完成度和综合能力，而不是固定日期。

**可运行形式：**

```text
先问：当前阶段是什么？已完成什么？质量证据是什么？
再决定：继续主线、进入综合训练、定向补弱、降低难度或延后。
没有质量证据时，不把“看过/做过”当作通过门槛。
```

**局限：** 来源中的分数段、时间节点和正确率阈值多为博主经验，不是官方规律，也没有足够个人数据支持直接硬编码。

### 模型三：用主动提取和跨章节混合训练对抗遗忘

**一句话：** 先合上材料主动重建知识结构，再用跨章节题组检验能否在切换场景中调用知识。

**来源证据：**

- `mmg-src-15`：A4 1.0 要求闭卷默写章节框架，A4 2.0 再增补陷阱和二级结论。
- `mmg-src-18`：拼好卷通过跨章节抽题和乱序回刷，处理战线过长造成的遗忘。
- `mmg-src-01`、`mmg-src-08`：A4 和二刷/三刷规划都强调从整体框架回到题目输出。

**可运行形式：**

```text
章节学习后：闭卷写框架 -> 对照补漏 -> 做题。
综合阶段：跨章节小题组/拼好卷 -> 按错误章节定向回刷 -> 再测。
如果整理开始挤压题目输出，停止扩张整理，保留未完成清单。
```

**局限：** A4 不是所有学习阶段都适用；拼好卷的题量、题型比例和频率需要个人数据校准，不能直接照搬博主示例。

### 模型四：以投入产出比管理难题，而不是追求全覆盖

**一句话：** 数学复习优先保证高频、基础和中等题的稳定得分，允许对低概率高耗时内容设置停止线。

**来源证据：**

- `mmg-src-16`：讲义和真题基础证明题要掌握，习题册偏难怪证明题不死磕。
- `mmg-src-07`、`mmg-src-03`：不把完成高难习题册当成所有人的必要条件。
- `mmg-src-09`：根据拼好卷暴露的错误进行定向回刷，而不是无限线性推进。

**可运行形式：**

```text
先判断题目是否属于核心题型、是否能形成可迁移方法、是否值得当前时间。
若是偏难怪且连续投入没有新信息，记录原因后暂时跳过。
跳过不是永久放弃；在讲义/真题基础未完成前，不得用该规则偷减核心训练。
```

**局限：** “偏难怪”的判定仍需用户或教师材料支持；目标高分、基础很强或临近考试时，取舍阈值可能不同。

### 模型五：通过即时反馈形成短周期纠错回路

**一句话：** 日常单题不要把错误积累到最后才处理，应在记忆仍清晰时完成订正并观察下一题是否能迁移。

**来源证据：**

- `mmg-src-12`：日常练习推荐做一题、对一题、解决后再进入下一题。
- `mmg-src-18`：综合训练后按错误章节回刷，而不是只统计完成套数。
- W35 执行观察将记录：错误节点、订正动作、下一题是否改善。

**可运行形式：**

```text
日常单题：完成 -> 对答案 -> 说清错误节点 -> 立即做下一题。
限时综合训练：先完成规定题组，再统一批改，避免破坏测试效度。
订正后必须留下一个可复述的错因或方法变化。
```

**局限：** 即时对答案不适用于全真限时模拟；如果每题反馈导致频繁中断，也需要退回整组批改。

## 4. 核心张力与处理方式

### 张力一：真题要尽早进入 vs 真题可能对顶尖学生信息增量有限

这不是一个可以统一成“越早越好”的规则。合理处理是按个人能力、强化完成度和训练目的分层：真题可用于建立考试感和诊断，但不应因博主对高手的经验直接改动当前用户路线。

### 张力二：完整掌握 vs 选择性舍弃

A4 和习题册提供系统性，证明题取舍和高难习题舍弃提供时间保护。二者的顺序应是：核心讲义/真题基础优先，确认低收益后才局部舍弃；不能把“性价比”变成逃避基础题。

### 张力三：严格执行主线 vs 根据反馈调整

博主一方面强调不要被多套建议干扰，另一方面又因为观察到学生遗忘而调整出拼好卷。综合后的模型不是“无条件服从”，而是：主线框架保持稳定，调整必须由真实错误和阶段证据触发。

### 张力四：高维整理 vs 直接做题

A4 可能提高框架调用能力，也可能吞噬题目时间。判断标准不是笔记是否漂亮，而是闭卷回忆后能否改善题目表现；不能改善就缩小或停止。

## 5. 不应从当前材料推出的结论

- 不能推出每天必须学习 9 小时或任何固定时长。
- 不能推出所有人都应该使用 A4、拼好卷或提前真题。
- 不能把博主对英语、政治的片段扩展成独立学科规划。
- 不能把博主经验当成官方大纲、学校要求或个人事实。
- 不能因为本周一次观察结果良好，就把候选规则晋升为 active。
- 不能用人物语气替代数学题的正式解答、教材和真题证据。
