# MMG Perspective

本目录保存“考研的秘密”相关材料，按科目或领域拆分。当前只建立数学模块。

## 模块

- `modules/math/`：数学来源、Phase 1.x 研究、候选规则、Phase 2 综合和未来数学 Skill。
- 后续英语、政治等内容必须进入独立模块，不与数学模块合并。

## 边界

- 这里保存外部材料的 AI 转译和研究过程，不是学习事实源。
- 候选规则不参与正式排程；用户个人执行结果仍只记录在 Daily 和周复盘。
- 完整人物 Skill 与领域方法模块要区分：当前只做数学方法模块，不宣称覆盖博主全部考研观点。
