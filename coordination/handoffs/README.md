# Handoffs

本目录只保存中断或阻塞工作的最小交接快照。接手流程和字段契约见 [[02_项目/考研Agent规划系统/HANDOFF|Agent 交接与故障切换]]。

- 文件名：`YYYY-MM-DD-HHmm-主题.md`。
- 有效状态：`active`、`resolved`。
- 已完成工作不创建快照，直接写回权威文件。
- 快照只引用正式周计划、Kanban block id 和相关事实，不复制任务 checkbox 或权威文件正文。
- 不保存密码、SSH 私钥、令牌、思维链或未脱敏生产日志。
